## Deploy
GitHub Pages can publish static files from a repository and supports custom domains.

1. Create a GitHub repository.
2. Upload the contents of this folder.
3. In Settings → Pages, select GitHub Actions as the source.
4. Push to `main`.
5. The included workflow deploys the site.

For a personal GitHub Pages site, use a repository named `<your-github-username>.github.io`.
